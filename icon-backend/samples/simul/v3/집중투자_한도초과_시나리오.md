# 집중투자 한도초과 시나리오

## 개요
펀드가 단일 종목 또는 발행사에 운용자산의 10%를 초과하여 투자하는 경우를 탐지합니다.

**탐지 목표**: SCN_CONC_001 (집중투자 한도초과)

**탐지 플로우**: Event Stream → Rule 필터링 (concentration_ratio > 0.10) → Scenario

**특징**: SINGLE_ROW 탐지, 단일 데이터소스, 비율 기반 한도 체크

---

## 실행 순서 (총 9건)
1. DS_FUND - 펀드 정보 등록 (2건)
2. DS_POSITION - 포지션 평가 (7건)

## 시나리오 설명

### 집중투자 리스크
펀드는 분산투자 원칙에 따라 단일 종목에 과도하게 집중 투자하지 않아야 합니다.
자본시장법 및 금융투자업규정에 따라 펀드는 단일 종목에 순자산의 10%를 초과하여 투자할 수 없습니다.

**정상 케이스**: 모든 종목이 10% 이하로 분산 투자
**위반 케이스**: 특정 종목 집중도 > 10%

### 탐지 조건
- **RULE_CONCENTRATION_SYMBOL**: concentration_ratio > 0.10
- **group_by_fields**: {fund_id, symbol}
- **탐지 시점**: 일별 평가 완료 후 (장 마감 후 배치)

### 규제 근거
- 자본시장법 시행령 제80조 (집합투자재산의 운용제한)
- 금융투자업규정 제4-54조 (펀드 집중투자 한도)

## 탐지 목적

### 집중투자 한도초과 (SCENARIO_INVESTMENT_CONCENTRATION_001)
펀드가 **단일 종목에 과도하게 집중 투자**하는 패턴을 탐지하여 규제 위반 및 투자 리스크를 경고합니다.

**탐지 조건**:
1. `concentration_ratio > 0.10` (집중도 10% 초과)
2. 펀드별, 종목별 개별 체크
3. 일별 평가 기준

**위험성**:
- **규제 위반**: 자본시장법 집중투자 한도 위반
- **과도한 리스크**: 단일 종목 의존도 높음
- **분산투자 원칙 훼손**: 포트폴리오 리스크 증가
- **가격 변동 민감**: 특정 종목 폭락 시 큰 손실
- **유동성 리스크**: 매도 시 시장 충격 가능

**정상 투자 패턴**:

## 💡 핵심 포인트

### 1. SINGLE_ROW 탐지
```json
// RULE_CONCENTRATION_SYMBOL
{
  "field": "concentration_ratio",
  "operator": "GREATER_THAN",
  "value": "0.10"
}
```
- 각 포지션 이벤트마다 즉시 체크
- 집계 불필요 (이미 계산된 비율 사용)
- 빠른 탐지 가능

### 2. 비율 기반 한도 체크
- **concentration_ratio**: 포지션금액 / 총운용자산
- **threshold**: 0.10 (10%)
- 절대 금액이 아닌 비율로 판단
- 펀드 규모와 무관하게 적용

### 3. 펀드별, 종목별 그룹핑
- **group_by_fields**: `{fund_id, symbol}`
- 각 펀드의 각 종목을 독립적으로 평가
- 펀드별 포트폴리오 리스크 관리

### 4. 일별 평가 기준
- **valuation_date**: 평가 기준일
- 장 마감 후 공식 종가로 평가
- 하루에 한 번 배치 탐지

## 🚨 추가 검증 포인트

### 펀드별 집중도 통계
```sql
SELECT
  event_data->>'fund_id' as fund_id,
  COUNT(*) as total_positions,
  COUNT(*) FILTER (WHERE (event_data->>'concentration_ratio')::numeric > 0.10) as violation_count,
  MAX((event_data->>'concentration_ratio')::numeric) as max_concentration,
  AVG((event_data->>'concentration_ratio')::numeric) as avg_concentration,
  SUM((event_data->>'position_value')::numeric) as total_position_value,
  MAX((event_data->>'total_fund_aum')::numeric) as fund_aum
FROM event_stream
WHERE data_source_id = 'DS_POSITION'
  AND event_dt::date = '2025-12-25'
GROUP BY event_data->>'fund_id'
ORDER BY violation_count DESC;
```

**예상 결과**:
| fund_id | total_positions | violation_count | max_concentration | avg_concentration | total_position | fund_aum |
|---------|-----------------|-----------------|-------------------|-------------------|----------------|----------|
| FUND001 | 4 | 1 | 0.12 | 0.095 | 380,000,000 | 1,000,000,000 | 🚨
| FUND002 | 3 | 1 | 0.119 | 0.076 | 183,000,000 | 800,000,000 | 🚨

### 발행사별 집중도 (추가 탐지 가능)
```sql
SELECT
  event_data->>'fund_id' as fund_id,
  event_data->>'issuer' as issuer,
  SUM((event_data->>'position_value')::numeric) as issuer_total,
  MAX((event_data->>'total_fund_aum')::numeric) as fund_aum,
  SUM((event_data->>'position_value')::numeric) / MAX((event_data->>'total_fund_aum')::numeric) as issuer_concentration
FROM event_stream
WHERE data_source_id = 'DS_POSITION'
  AND event_dt::date = '2025-12-25'
GROUP BY event_data->>'fund_id', event_data->>'issuer'
HAVING SUM((event_data->>'position_value')::numeric) / MAX((event_data->>'total_fund_aum')::numeric) > 0.10
ORDER BY issuer_concentration DESC;
```

**용도**: 발행사 집중도 체크 (향후 확장)
