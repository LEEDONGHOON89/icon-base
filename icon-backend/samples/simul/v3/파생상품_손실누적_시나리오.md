# 파생상품 손실누적 시나리오

## 개요
고객이 30일 내 5회 이상 파생상품 거래에서 손실을 기록하여 투자 리스크가 누적되는 경우를 탐지합니다.

**탐지 목표**: SCN_DERIV001 (파생상품 손실누적)

**탐지 플로우**: Event Stream → Rule 필터링 → Aggregate (COUNT) → Scenario

**특징**: 단순 COUNT 집계, 단일 데이터소스, 시간 윈도우 30일

## 시나리오 설명

파생상품은 고위험 고수익 상품으로, 단기간 반복적인 손실은 고객의 투자 전략 문제나 리스크 관리 부실을 나타냅니다.
30일 내 5회 이상 손실 발생 시 투자 중단 권고 또는 리스크 재평가가 필요합니다.

- **정상 케이스**: 손익이 균형 있게 발생, 손실 빈도 낮음
- **탐지 케이스**: 30일 내 동일 고객이 5회 이상 손실 발생
- **필터링**: RULE_DERIVATIVE_LOSS (profit_loss < 0)

## 검증 SQL

### 1. 고객 엔티티 확인
```sql
SELECT entity_type, entity_id, attributes->>'customer_name', attributes->>'risk_grade'
FROM entity_attributes
WHERE entity_type = 'CUSTOMER'
  AND entity_id IN ('CUST001', 'CUST002')
ORDER BY entity_id;
```

**예상**: CUST001, CUST002 생성

### 2. 이벤트 스트림 확인
```sql
SELECT
  event_stream_id,
  event_data->>'transaction_id' as transaction_id,
  event_data->>'customer_id' as customer_id,
  event_data->>'product_name' as product_name,
  (event_data->>'profit_loss')::numeric as profit_loss,
  event_dt
FROM event_stream
WHERE data_source_id = 'DS_DERIVATIVE'
  AND event_data->>'customer_id' = 'CUST001'
ORDER BY event_dt;
```

**예상**: 5건의 손실 거래 (profit_loss < 0)

### 3. 룰 매칭 확인
```sql
SELECT
  event_stream_id,
  event_data->>'transaction_id' as transaction_id,
  event_data->>'customer_id' as customer_id,
  (event_data->>'profit_loss')::numeric as profit_loss
FROM event_stream
WHERE data_source_id = 'DS_DERIVATIVE'
  AND (event_data->>'profit_loss')::numeric < 0
  AND event_data->>'customer_id' = 'CUST001'
ORDER BY event_dt;
```

**예상**: CUST001의 5건 모두 매칭 (RULE_DERIVATIVE_LOSS)

### 4. 집계 결과 확인

## 탐지 목적

### 파생상품 손실누적 (SCENARIO_DERIVATIVE_RISK_001)
고객이 **단기간 반복적으로 파생상품 거래에서 손실**을 기록하는 패턴을 탐지하여 투자 리스크 관리 필요성을 경고합니다.

**탐지 조건**:
1. `profit_loss < 0` (손실 발생 거래)
2. 30일 내 동일 고객
3. 5회 이상 손실 발생 (`threshold_count=5`)

**위험성**:
- **투자 전략 부재**: 무분별한 파생상품 거래
- **손실 누적**: 단기간 큰 손실 발생 가능
- **리스크 관리 부실**: 손절매 타이밍 놓침
- **고객 보호**: 추가 손실 방지 필요
- **부적합 투자**: 고객 성향과 맞지 않는 상품

**정상 투자 패턴**:
- 정상: 손익이 균형 있게 분산, 손실 빈도 낮음
- 비정상: 30일 내 5회 이상 지속적 손실 (리스크 관리 부실)

**권장 조치**:
- 고객 상담 및 투자 전략 재검토
- 파생상품 거래 일시 중단 권고
- 리스크 등급 재평가
- 손실 한도 설정

## 🚨 추가 검증 포인트

### 고객별 손실 통계
```sql
SELECT
  event_data->>'customer_id' as customer_id,
  COUNT(*) as total_trades,
  COUNT(*) FILTER (WHERE (event_data->>'profit_loss')::numeric < 0) as loss_count,
  COUNT(*) FILTER (WHERE (event_data->>'profit_loss')::numeric > 0) as profit_count,
  SUM((event_data->>'profit_loss')::numeric) as total_pnl,
  AVG((event_data->>'profit_loss')::numeric) as avg_pnl
FROM event_stream
WHERE data_source_id = 'DS_DERIVATIVE'
  AND event_dt >= NOW() - INTERVAL '30 days'
GROUP BY event_data->>'customer_id'
ORDER BY loss_count DESC;
```

**예상 결과**:
| customer_id | total_trades | loss_count | profit_count | total_pnl | avg_pnl |
|-------------|--------------|------------|--------------|-----------|---------|
| CUST001 | 5 | 5 | 0 | -1,340,000 | -268,000 | 🚨
| CUST002 | 1 | 0 | 1 | +60,000 | +60,000 | ✅

### 30일 윈도우 내 이벤트 확인
```sql
SELECT
  event_data->>'customer_id' as customer_id,
  event_data->>'transaction_id' as transaction_id,
  (event_data->>'profit_loss')::numeric as profit_loss,
  event_dt,
  event_dt >= (
    SELECT MAX(event_dt) - INTERVAL '30 days'
    FROM event_stream
    WHERE data_source_id = 'DS_DERIVATIVE'
      AND event_data->>'customer_id' = 'CUST001'
  ) as within_window
FROM event_stream
WHERE data_source_id = 'DS_DERIVATIVE'
  AND event_data->>'customer_id' = 'CUST001'
ORDER BY event_dt;
```

**예상**: 5건 모두 within_window=true
