# 긴급승인 다발 탐지 시나리오

## 개요
동일 직원이 **월 5회 초과 긴급승인**을 수행하면 탐지합니다.

**탐지 목표**: S_URGENT_APPR (긴급승인 다발 탐지)

**탐지 플로우**: Event Stream → Aggregate (where_json 필터링) → Scenario

## 검증 SQL

### 1. 직원 엔티티 확인
```sql
SELECT entity_type, entity_id, attributes->>'emp_name'
FROM entity_attributes
WHERE entity_type = 'EMPLOYEE' AND entity_id IN ('EMP020', 'EMP021')
ORDER BY entity_id;
```

### 2. 이벤트 스트림 확인
```sql
SELECT
  event_stream_id,
  event_data->>'transaction_id' as tx_id,
  event_data->>'login_id' as login_id,
  event_data->>'approver_id' as approver_id,
  event_data->>'is_urgent_approval' as is_urgent
FROM event_stream
WHERE data_source_id = 'DS_XFER_APPR'
  AND event_data->>'login_id' = 'EMP020'
ORDER BY event_dt;
```

**예상**: 6건, `is_urgent_approval: true`

### 3. 집계 결과 확인
```sql
SELECT
  aggregate_id,
  group_key,
  matched_count,
  threshold_count,
  pass,
  detected_at
FROM detect_aggregates
WHERE aggregate_id = 'AGG_URGENT_APPR_CNT'
  AND group_key = 'EMP020';
```

**예상**: matched_count=6, threshold_count=5, pass=true

### 4. 시나리오 탐지 확인
```sql
SELECT
  scenario_id,
  group_key,
  detected_at
FROM detect_scenarios
WHERE scenario_id = 'S_URGENT_APPR'
  AND group_key = 'EMP020';
```

**예상**: S_URGENT_APPR 탐지 (EMP020)
