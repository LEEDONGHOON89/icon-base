# 자기승인 거래 탐지 시나리오

## 개요
이체 요청자와 승인자가 동일한 **자기승인** 거래를 탐지합니다.

**탐지 목표**: SCN_SELF_APPR (자기승인 거래 탐지)

**탐지 플로우**: Event Stream → Derived Field → Aggregate (where_json 필터링) → Scenario

---

## 1단계: 직원 HR 등록 (DS_EMPLOYEE)

```json
[
  {"hr_tx_id": "HR20251215001", "employee_id": "EMP001", "emp_name": "김철수", "dept_name": "자금운용팀", "job_title": "과장", "status": "ACTIVE", "perm_level": 5, "hire_date": "2020-03-15", "last_update": "2025-01-15 09:00:00"}
]
```

**예상**: EMPLOYEE 엔티티 1개 생성
- EMP001 (김철수, 과장) - 요청자이자 승인자

---

## 2단계: 자기승인 이체 거래 (DS_XFER_APPR)

```json
[
  {"transaction_id": "XFER_20251215_001", "transaction_datetime": "2025-12-15 14:30:00", "transaction_date": "2025-12-15", "amount": 50000000, "customer_id": "CORP_001", "customer_name": "(주)테스트기업", "sender_account": "110-123-456789", "receiver_account": "220-987-654321", "receiver_name": "협력업체A", "receiver_bank_code": "020", "login_id": "EMP001", "approver_id": "EMP001", "approval_datetime": "2025-12-15 14:30:05", "approval_level": "1차", "channel": "인터넷뱅킹", "branch_code": "001"}
]
```

**예상**:
- ✅ SCN_SELF_APPR 시나리오 탐지 (group_key: EMP001)
- login_id = approver_id = "EMP001" (자기승인)

## 검증 SQL

### 1. 직원 엔티티 확인
```sql
SELECT entity_type, entity_id, attributes->>'emp_name'
FROM entity_attributes
WHERE entity_type = 'EMPLOYEE' AND entity_id = 'EMP001';
```

### 2. 이벤트 스트림 확인
```sql
SELECT
  event_stream_id,
  event_data->>'transaction_id' as tx_id,
  event_data->>'login_id' as login_id,
  event_data->>'approver_id' as approver_id,
  event_data->'derived_fields'->>'is_self_approved' as is_self_approved
FROM event_stream
WHERE data_source_id = 'DS_XFER_APPR'
  AND event_data->>'transaction_id' = 'XFER_20251215_001';
```

**예상**: 1건, `is_self_approved: true`

### 3. 집계 결과 확인
```sql
SELECT
  aggregate_id,
  group_key,
  matched_count,
  threshold_count,
  pass,
  detected_at
FROM detect_aggregates
WHERE aggregate_id = 'AGG_SELF_APPR'
  AND group_key = 'EMP001';
```

**예상**: matched_count=1, threshold_count=1, pass=true

### 4. 시나리오 탐지 확인
```sql
SELECT
  scenario_id,
  group_key,
  detected_at
FROM detect_scenarios
WHERE scenario_id = 'SCN_SELF_APPR'
  AND group_key = 'EMP001';
```

**예상**: SCN_SELF_APPR 탐지 (EMP001)

## 탐지 흐름

```
거래 발생: login_id = approver_id (EMP001)
              ↓
1. Event Stream 생성
   - login_id: EMP001
   - approver_id: EMP001
              ↓
2. Derived Rule #8 실행
   - is_self_approved: true (파생)
              ↓
3. AGG_SELF_APPR 집계
   - where_json으로 is_self_approved=true 필터링
   - group_key: EMP001
   - 1분 내 1건 → 탐지!
              ↓
4. SCN_SELF_APPR 시나리오 탐지
   - risk_level: HIGH
   - 직무분리 위반
```

### 탐지 포인트

| 항목 | 값 | 탐지 | 설명 |
|------|-----|------|------|
| 요청자 | EMP001 | - | 김철수 (과장) |
| 승인자 | EMP001 | 🚨 동일 | 본인 승인 |
| is_self_approved | true | 🚨 자기승인 | 파생 필드로 자동 계산 |
| 금액 | 50,000,000원 | - | 5천만원 (고액) |

**탐지 이유**: 직무분리 원칙(Segregation of Duties) 위반으로 내부통제 우회 가능
