# 대리승인 다발 탐지 시나리오

## 개요
요청자와 승인자가 다른 **대리승인**이 **월 10회 초과** 발생하면 탐지합니다.

**탐지 목표**: S_PROXY_APPR (대리승인 다발 탐지)

**탐지 플로우**: Event Stream → Aggregate (where_json 필터링) → Scenario

## 검증 SQL

### 1. 직원 엔티티 확인
```sql
SELECT entity_type, entity_id, attributes->>'emp_name', attributes->>'dept_name'
FROM entity_attributes
WHERE entity_type = 'EMPLOYEE'
  AND entity_id IN ('EMP010', 'EMP011', 'EMP012', 'EMP013')
ORDER BY entity_id;
```

### 2. 이벤트 스트림 확인
```sql
SELECT
  event_stream_id,
  event_data->>'transaction_id' as tx_id,
  event_data->>'login_id' as login_id,
  event_data->>'approver_id' as approver_id,
  event_data->'derived_fields'->>'is_self_approved' as is_self_approved
FROM event_stream
WHERE data_source_id = 'DS_XFER_APPR'
  AND event_data->>'login_id' = 'EMP010'
ORDER BY event_dt;
```

**예상**: 11건, `is_self_approved: false`

### 3. 집계 결과 확인
```sql
SELECT
  aggregate_id,
  group_key,
  matched_count,
  threshold_count,
  pass,
  detected_at
FROM detect_aggregates
WHERE aggregate_id = 'AGG_PROXY_APPR_CNT'
  AND group_key = 'EMP010';
```

**예상**: matched_count=11, threshold_count=10, pass=true

### 4. 시나리오 탐지 확인
```sql
SELECT
  scenario_id,
  group_key,
  detected_at
FROM detect_scenarios
WHERE scenario_id = 'S_PROXY_APPR'
  AND group_key = 'EMP010';
```

**예상**: S_PROXY_APPR 탐지 (EMP010)
