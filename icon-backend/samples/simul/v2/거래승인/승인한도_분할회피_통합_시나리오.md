# 승인한도 분할회피 탐지 통합 시나리오

## 개요
동일 요청자가 **1시간 내 동일 수취계좌로 3건 이상** 이체하여 **합계 1억원 이상**일 때 탐지합니다.

**탐지 목표**: SCN_SPLIT_LMT (승인한도 분할회피)

**탐지 플로우**: Event Stream → Aggregate (필터링 없음) → Scenario

**특징**: 모든 이체 거래를 대상으로 집계 (자기승인, 타인승인 구분 없음)

---

## 실행 순서 (총 5건)
1. DS_EMPLOYEE - 직원 HR 등록 (2건)
2. DS_XFER_APPR - 이체 거래 (3건)

## 검증 SQL

### 1. 직원 엔티티 확인
```sql
SELECT entity_type, entity_id, attributes->>'emp_name'
FROM entity_attributes
WHERE entity_type = 'EMPLOYEE' AND entity_id IN ('EMP004', 'EMP005')
ORDER BY entity_id;
```

**예상**: EMP004, EMP005 생성

### 2. 이벤트 스트림 확인
```sql
SELECT
  event_stream_id,
  event_data->>'transaction_id' as tx_id,
  event_data->>'login_id' as login_id,
  event_data->>'target_account' as target_account,
  event_data->>'amount' as amount,
  event_dt
FROM event_stream
WHERE transaction_id LIKE 'XFER_20251215_SPLIT_%'
ORDER BY event_dt;
```

**예상**: 3건, 모두 동일 수취계좌(330-444-555666), 각 40,000,000원

### 3. 집계 결과 확인
```sql
SELECT
  aggregate_id,
  group_key,
  matched_count,
  threshold_count,
  pass,
  detected_at
FROM detect_aggregates
WHERE aggregate_id = 'AGG_SPLIT_LIMIT'
  AND group_key = 'EMP004|330-444-555666';
```

**예상**: matched_count=120000000, threshold_count=3, threshold_amount=100000000, pass=true

### 4. 시나리오 탐지 확인
```sql
SELECT
  scenario_id,
  group_key,
  detected_at
FROM detect_scenarios
WHERE scenario_id = 'SCN_SPLIT_LMT'
  AND group_key LIKE 'EMP004%';
```

**예상**: SCN_SPLIT_LMT 탐지 (group_key: EMP004|330-444-555666)

## 탐지 흐름

```
동일 요청자 → 동일 수취계좌 이체 (1시간 내 반복)
              ↓
1. Event Stream 생성 (모든 TRANSFER)
   - login_id: EMP004
   - receiver_account: 330-444-555666
   - amount: 40,000,000원
              ↓
2. AGG_SPLIT_LIMIT 집계 (필터링 없음)
   - group_by: {login_id, receiver_account}
   - 1시간 내 3건 이상 && 합계 1억원 이상
   - sum(amount) = 120,000,000원 → 탐지!
              ↓
3. SCN_SPLIT_LMT 시나리오 탐지
   - risk_level: HIGH
   - 승인한도 회피 의심
```

## 탐지 목적

동일 요청자가 짧은 시간 내에 동일 수취계좌로 여러 건의 거래를 분할하여 **승인 한도를 회피**하는 패턴을 탐지합니다.

**탐지 조건**:
1. 동일 요청자 (login_id)
2. 동일 수취계좌 (receiver_account)
3. 1시간 내 3건 이상 이체
4. 합계 금액 1억원 이상

**핵심**: 필터링 없이 모든 이체 거래를 대상으로 하므로 자기승인/타인승인 구분 없이 분할 패턴을 포착합니다.
