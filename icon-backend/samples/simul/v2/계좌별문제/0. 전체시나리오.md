# 전체 시나리오 통합 실행 (단일실행 탭용)

## 개요
모든 DataSource의 데이터를 하나의 JSON 배열로 구성하여 순차적으로 실행할 수 있습니다.
같은 DataSource의 데이터는 `data` 배열로 묶어서 관리합니다.

## 실행 순서 (총 20건)
1. DS_EMPLOYEE - 직원 HR 등록 (5건)
2. DS_EMP_ACC - 직원 계좌 등록 (3건)
3. DS_CUST_ACC - 고객 계좌 등록 (2건)
4. DS_CORPORATE - 법인 정보 등록 (2건)
5. DS_CORP_ACC - 법인 계좌 등록 (2건)
6. DS_XFER_APPR - 이체 거래 (6건)

## 예상 탐지 결과

### 1. S_EMP_SELF_AC (직원 본인계좌 이상거래)
- XFER_EMP_SELF_001: 고객 → 직원(EMP001) 본인계좌
- XFER_EMP_SELF_002: 고객 → 직원(EMP001) 본인계좌

### 2. S_EMP_FAM_AC (직원 가족계좌 이상거래)
- XFER_FAM_001: 고객 → 직원(EMP001) 가족계좌
- XFER_FAM_002: 고객 → 직원(EMP001) 가족계좌

### 3. S_CORP_TO_EMP (법인계좌→직원 이상거래)
- XFER_20251201_001: 법인계좌 → 직원 계좌
- XFER_20251203_005: 법인계좌 → 직원 계좌
