# 법인계좌→직원계좌 이체 탐지 시나리오

## 개요
법인계좌에서 직원계좌로 이체가 발생하면 **즉시 탐지**합니다.

**탐지 목표**: S_CORP_TO_EMP (법인계좌→직원계좌 이체 탐지)

**탐지 플로우**: Event Stream → Aggregate (where_json 필터링) → Scenario

## 검증 SQL

### 1. 엔티티 확인
```sql
-- 직원 엔티티
SELECT entity_type, entity_id, attributes->>'emp_name'
FROM entity_attributes
WHERE entity_type = 'EMPLOYEE' AND entity_id IN ('EMP030', 'EMP031')
ORDER BY entity_id;

-- 법인 엔티티
SELECT entity_type, entity_id, attributes->>'corp_name'
FROM entity_attributes
WHERE entity_type = 'CORPORATE' AND entity_id IN ('CORP_030', 'CORP_031')
ORDER BY entity_id;
```

### 2. 이벤트 스트림 확인
```sql
SELECT
  event_stream_id,
  event_data->>'transaction_id' as tx_id,
  event_data->>'source_account' as source_account,
  event_data->>'target_account' as target_account,
  event_data->>'is_corporate_source' as is_corporate_source,
  event_data->>'is_employee_target' as is_employee_target
FROM event_stream
WHERE data_source_id = 'DS_XFER_APPR'
  AND event_data->>'is_corporate_source' = 'true'
  AND event_data->>'is_employee_target' = 'true'
ORDER BY event_dt;
```

**예상**: 2건 모두 is_corporate_source=true, is_employee_target=true

### 3. 집계 결과 확인
```sql
SELECT
  aggregate_id,
  group_key,
  matched_count,
  threshold_count,
  pass,
  detected_at
FROM detect_aggregates
WHERE aggregate_id = 'AGG_CORP_TO_EMP_CNT'
ORDER BY group_key;
```

**예상**:
- group_key=220-333-444555: matched_count=1, threshold_count=1, pass=true (탐지)
- group_key=330-444-555666: matched_count=1, threshold_count=1, pass=true (탐지)

### 4. 시나리오 탐지 확인
```sql
SELECT
  scenario_id,
  group_key,
  detected_at
FROM detect_scenarios
WHERE scenario_id = 'S_CORP_TO_EMP'
ORDER BY detected_at;
```

**예상**: S_CORP_TO_EMP 2건 탐지
- group_key: 220-333-444555 (12/01)
- group_key: 330-444-555666 (12/03)

## 탐지 흐름

```
법인계좌 → 직원계좌 이체 발생
              ↓
1. Event Stream 생성
   - is_corporate_source: true (기존 필드)
   - is_employee_target: true (기존 필드)
              ↓
2. AGG_CORP_TO_EMP_CNT 집계
   - where_json으로 2개 조건 AND 필터링
   - group_key: receiver_account
   - threshold_count=1 → 즉시 탐지!
              ↓
3. S_CORP_TO_EMP 시나리오 탐지
   - risk_level: REVIEW
   - 횡령/자금유용 가능성
```

### 탐지 패턴

```
케이스 1: CORP_030 → EMP030
└─ 12/01: 5,000,000원 (법인계좌 → 직원계좌) → 🚨 즉시 탐지!

케이스 2: CORP_031 → EMP031
└─ 12/03: 1,500,000원 (법인계좌 → 직원계좌) → 🚨 즉시 탐지!
```

## 탐지 목적

법인 자금이 직원 개인 계좌로 이체되는 경우, **횡령이나 부정 자금 유용** 가능성이 있어 즉시 모니터링이 필요합니다.

**탐지 조건**:
1. 출금계좌가 법인 소유 (`is_corporate_source = true`)
2. 입금계좌가 직원 소유 (`is_employee_target = true`)
3. 발생 즉시 탐지 (`threshold_count = 1`)
