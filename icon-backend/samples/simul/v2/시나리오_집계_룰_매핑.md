### 2. ⚠️ where_json 오류

#### AGG_CUST_TO_FAM (고객→직원가족계좌 이체건수)

**현재 (잘못됨)**:
```json
[
  {"fieldName": "is_customer_sender", "operator": "EQUALS", "value": false},
  {"fieldName": "is_employee_family_receiver", "operator": "EQUALS", "value": false}
]
```

**수정 필요**:
```json
[
  {"fieldName": "is_customer_sender", "operator": "EQUALS", "value": true},
  {"fieldName": "is_employee_family_receiver", "operator": "EQUALS", "value": true}
]
```

**수정 SQL**:
```sql
UPDATE aggregates
SET where_json = '[
  {"fieldName": "is_customer_sender", "operator": "EQUALS", "value": true},
  {"fieldName": "is_employee_family_receiver", "operator": "EQUALS", "value": true}
]'::jsonb
WHERE aggregate_id = 'AGG_CUST_TO_FAM';
```

**연결된 룰도 수정 필요**:
```sql
UPDATE rules
SET where_json = '[
  {"fieldName": "is_customer_sender", "operator": "EQUALS", "value": true},
  {"fieldName": "is_employee_family_receiver", "operator": "EQUALS", "value": true}
]'::jsonb
WHERE rule_id = 'R_CUST_TO_FAM';
```

### 3. ⚠️ where_json 형식 불일치

#### AGG_NO_APPROVAL_CNT (승인 누락 이체 집계)

**현재**:
```json
{"approval_datetime": null}
```

**표준 형식으로 수정 권장**:
```json
[
  {"fieldName": "approval_datetime", "operator": "IS_NULL", "value": null}
]
```

또는 IS_NULL 연산자가 없다면:
```json
[
  {"fieldName": "approver_id", "operator": "IS_NULL", "value": null}
]
```

**수정 SQL**:
```sql
UPDATE aggregates
SET where_json = '[
  {"fieldName": "approver_id", "operator": "IS_NULL", "value": null}
]'::jsonb
WHERE aggregate_id = 'AGG_NO_APPROVAL_CNT';
```
