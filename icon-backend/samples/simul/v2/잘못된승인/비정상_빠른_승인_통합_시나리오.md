# 비정상 빠른 승인 통합 시나리오

## 개요
승인자가 10초 이내로 승인을 처리하여 부실 심사 가능성이 있는 경우를 탐지합니다.

**탐지 목표**: SCN_FAST_APPR (비정상적으로 빠른 승인)

**탐지 플로우**: Event Stream → Derived Field → Aggregate (where_json 필터링) → Scenario

**특징**: Rule 없이 where_json으로 직접 필터링, 파생 필드 자동 계산

---

## 실행 순서 (총 3건)
1. DS_EMPLOYEE - 직원 HR 등록 (2건)
2. DS_XFER_APPR - 이체 거래 (1건)

## 시나리오 설명

정상적인 승인 프로세스는 거래 내용 검토, 승인 사유 확인 등으로 최소 수십 초 이상 소요됩니다.
10초 이내 승인이 발생하면 제대로 된 검토 없이 자동 승인되었을 가능성이 있습니다.

- **정상 케이스**: 승인 소요 시간 30초 ~ 수분
- **탐지 케이스**: 1시간 내 동일 승인자가 10초 이내 승인 1건 이상
- **필터링 없음**: predicate_rule_id=NULL, where_json으로 직접 필터링

## 탐지 흐름

```
이체 거래 등록 (DS_XFER_APPR)
              ↓
1. Event Stream 생성
   - approval_request_dt: 2025-12-20 14:00:00
   - approval_datetime: 2025-12-20 14:00:05
              ↓
2. Derived Field 자동 계산 (DerivedFieldService)
   - approval_duration_sec = approval_datetime - approval_request_dt
   - 결과: 5초
              ↓
3. AGG_FAST_APPR 집계 (where_json 필터링)

   - matched_count=1, threshold_count=1 → 탐지!

4. SCN_FAST_APPR 시나리오 탐지

   - risk_level: INTENSIVE
   - 부실 심사 가능성
```

## 탐지 목적

### 비정상 빠른 승인 (SCN_FAST_APPR)
승인 요청 후 **비정상적으로 짧은 시간 내 승인**된 거래를 탐지하여 부실 심사 가능성을 경고합니다.

**탐지 조건**:
1. `approval_duration_sec ≤ 10` (승인 소요시간 10초 이하)
2. 1시간 내 동일 승인자
3. 1건만 있어도 즉시 탐지 (`threshold_count=1`)

**위험성**:
- **자동 승인**: 검토 없이 자동으로 승인
- **부실 심사**: 거래 내용 미검토
- **내부 통제 우회**: 승인 프로세스 형식화
- **담합 가능성**: 요청자-승인자 간 사전 조율

**정상 승인 시간**:
- 정상: 30초 ~ 수분 (거래 내역 검토, 승인 사유 확인)
- 비정상: 10초 이하 (자동 승인 또는 부실 심사 의심)

## 💡 핵심 포인트

### 1. Rule 없이 Aggregate에서 직접 필터링
```json
// predicate_rule_id = NULL
// where_json으로 직접 조건 설정
{
  "fieldName": "approval_duration_sec",
  "operator": "LESS_THAN_OR_EQUALS",
  "value": 10
}
```

### 2. 파생 필드 자동 계산
- **DerivedFieldService**가 자동으로 `approval_duration_sec` 계산
- **DatetimeDiffSecondsStrategy** 사용
- event_stream 저장 시 자동 포함

### 3. Threshold 1건
- 기존: 3건 이상 탐지
- 변경: **1건만 있어도 탐지** (더 민감한 탐지)
- 첫 번째 빠른 승인부터 즉시 경고

### 4. 간소화된 흐름
- DS_XFER_APPR만 사용 (DS_APPROVAL_PROCESS 불필요)
- 파생 필드로 충분히 탐지 가능

## 🚨 추가 검증 포인트

### 승인자별 평균 승인 소요 시간
```sql
SELECT
  event_data->>'approver_id' as approver_id,
  AVG((event_data->>'approval_duration_sec')::int) as avg_duration,
  MIN((event_data->>'approval_duration_sec')::int) as min_duration,
  MAX((event_data->>'approval_duration_sec')::int) as max_duration,
  COUNT(*) as approval_count
FROM event_stream
WHERE data_source_id = 'DS_XFER_APPR'
  AND event_data ? 'approval_duration_sec'
GROUP BY event_data->>'approver_id'
ORDER BY avg_duration ASC;
```

**예상 결과**:
| approver_id | avg_duration | min_duration | max_duration | approval_count |
|-------------|--------------|--------------|--------------|----------------|
| EMP022 | 5초 | 5초 | 5초 | 1건 | 🚨
