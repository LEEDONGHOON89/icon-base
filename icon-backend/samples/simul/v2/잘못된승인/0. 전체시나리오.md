# 잘못된 승인 탐지 통합 시나리오

## 개요
승인 누락 및 비정상적으로 빠른 승인 패턴을 탐지하는 시나리오입니다.

## 탐지 시나리오
- SCN_NO_APPR (승인 누락): 1건
- SCN_FAST_APPR (비정상 빠른 승인): 1건

## 데이터소스
1. DS_EMPLOYEE - 직원 HR 등록 (3건)
2. DS_XFER_APPR - 이체 거래 (2건)
