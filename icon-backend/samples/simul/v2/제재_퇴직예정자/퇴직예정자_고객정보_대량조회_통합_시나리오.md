## 검증 SQL

### 1단계 검증
```sql
SELECT entity_type, entity_id, attributes->>'emp_name', attributes->>'status'
FROM entity_attributes
WHERE entity_type = 'EMPLOYEE';
```

### 2단계 검증
```sql
-- 접근 로그 확인
SELECT event_id, event_data->>'transaction_id', event_data->>'USER_ID', 
       event_data->>'DB_TABLE', event_data->>'DATA_VOLUME'
FROM event_stream
WHERE data_source_id = '0MACCESS1DS'
ORDER BY event_time DESC
LIMIT 10;

-- 탐지 확인
SELECT scenario_id, group_key, detected_at, risk_level
FROM detect_scenarios
WHERE scenario_id = 'S_RESIGN_BULK';
```
