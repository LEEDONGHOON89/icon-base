# 전체 시나리오 통합 실행 (단일실행 탭용)

## 개요
모든 통합 시나리오의 데이터를 하나의 JSON 배열로 구성하여 순차적으로 실행할 수 있습니다.
같은 DataSource의 데이터는 `data` 배열로 묶어서 관리합니다.

## 탐지 시나리오
- 제재대상 거래시도(S_SANC_VIOL): 2건
- 퇴직예정자 고객정보 대량조회(S_RESIGN_BULK): 1건

## 데이터소스
1. DS_EMPLOYEE - 직원 HR 등록 (5건)
2. DS_EMP_ACC - 직원 계좌 등록 (3건)
3. DS_CUST_ACC - 고객 계좌 등록 (5건)
4. DS_SANCTIONS - 제재 리스트 등록 (5건)
5. 0MACCESS1DS - 시스템 접근 로그 (4건)
6. DS_XFER_APPR - 이체 거래 (12건)

## 예상 탐지 결과

### 1. S_EMP_FAM_AC (직원 가족계좌 이상거래)
- XFER_FAM_001: 고객 → 직원(EMP001) 가족계좌
- XFER_FAM_002: 고객 → 직원(EMP001) 가족계좌

### 2. S_EMP_SELF_AC (직원 본인계좌 이상거래)
- XFER_EMP_SELF_001: 고객 → 직원(EMP001) 본인계좌
- XFER_EMP_SELF_002: 고객 → 직원(EMP001) 본인계좌
- XFER_EMP_SELF_003: 고객 → 직원(EMP002) 본인계좌

### 3. S_SANC_VIOL (제재대상 거래시도)
- XFER_SANCTIONS_TEST_001: 제재대상(John Terrorist) 거래
- XFER_SANCTIONS_TEST_002: 제재대상(DPRK Trading Corp) 거래

### 4. S_RESIGN_BULK (퇴직예정자 고객정보 대량조회)
- EMP001: 퇴직예정, 대량조회 3건 (BULK_QUERY)
