# 제재대상 거래시도 통합 시나리오

## 개요
제재 대상(OFAC, UN, EU, 국내 제재 리스트)으로 이체 시도 시 **즉시 탐지**합니다.

**탐지 목표**: S_SANC_VIOL (제재대상 거래시도)

**탐지 플로우**: Event Stream → Derived Field → Aggregate (where_json 필터링) → Scenario

## 검증 SQL

### 1단계 검증
```sql
SELECT entity_type, entity_id, attributes->>'name', attributes->>'list_type', attributes->>'is_active'
FROM entity_attributes
WHERE entity_type = 'SANCTIONED_ENTITY';
```

### 2. 이벤트 스트림 확인
```sql
SELECT
  event_stream_id,
  event_data->>'transaction_id' as tx_id,
  event_data->>'customer_id' as customer_id,
  event_data->>'receiver_name' as receiver_name,
  event_data->>'is_sanctioned' as is_sanctioned
FROM event_stream
WHERE data_source_id = 'DS_XFER_APPR'
ORDER BY event_dt;
```

**예상**: 5건 중 2건만 is_sanctioned=true

### 3. 집계 결과 확인
```sql
SELECT
  aggregate_id,
  group_key,
  matched_count,
  threshold_count,
  pass,
  detected_at
FROM detect_aggregates
WHERE aggregate_id = 'AGG_SANCTIONS_VIOLATION_CNT'
ORDER BY group_key;
```

**예상**:
- group_key=CUST_100: matched_count=1, threshold_count=1, pass=true (탐지)
- group_key=CUST_101: matched_count=1, threshold_count=1, pass=true (탐지)

### 4. 시나리오 탐지 확인
```sql
SELECT
  scenario_id,
  group_key,
  detected_at
FROM detect_scenarios
WHERE scenario_id = 'S_SANC_VIOL'
ORDER BY detected_at;
```

**예상**: S_SANC_VIOL 2건 탐지
- group_key: CUST_100 (John Terrorist)
- group_key: CUST_101 (DPRK Trading Corp)

## 탐지 흐름

```
제재 대상으로 이체 시도
              ↓
1. Event Stream 생성
   - receiver_name: John Terrorist
              ↓
2. Derived Rule 실행
   - is_sanctioned: true (SANCTIONED_ENTITY 매칭)
              ↓
3. AGG_SANCTIONS_VIOLATION_CNT 집계
   - where_json으로 is_sanctioned=true 필터링
   - group_key: customer_id (CUST_100)
   - threshold_count=1 → 즉시 탐지!
              ↓
4. S_SANC_VIOL 시나리오 탐지
   - risk_level: CRITICAL
   - 제재 대상 거래 시도
```

### 탐지 패턴

```
케이스 1: CUST_100 → John Terrorist (OFAC)
└─ 12/16 10:00: 50,000원 (제재 대상) → 🚨 즉시 탐지!

케이스 2: CUST_101 → DPRK Trading Corp (UN)
└─ 12/16 11:00: 1,000,000원 (제재 대상) → 🚨 즉시 탐지!

케이스 3: CUST_102 → 일반거래처A, B
├─ 12/16 12:00: 500,000원 (정상)
└─ 12/16 14:00: 300,000원 (정상) → ✅ 미탐지

케이스 4: CUST_103 → Former Sanctioned
└─ 12/16 15:00: 200,000원 (제재 해제됨, is_active=false) → ✅ 미탐지
```

## 탐지 목적

국제 제재 대상(OFAC, UN, EU) 및 국내 제재 대상으로의 자금 이동을 실시간으로 차단하기 위해, **단 1건의 이체 시도라도 즉시 탐지**합니다.

**탐지 조건**:
1. 수취인(receiver_name)이 활성 제재 리스트에 존재 (`is_active = true`)
2. 발생 즉시 탐지 (`threshold_count = 1`)
3. 제재 해제된 대상은 미탐지 (`is_active = false`)

**핵심**: 파생 룰로 제재 여부를 판단하고, where_json으로 제재 대상만 필터링하여 즉시 탐지합니다.
