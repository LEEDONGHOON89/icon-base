- **S_EDLY_ND_HI** (고령자 비대면계좌개설 후 24시간 내 고액이체)

## 🎯 탐지 조건
[README.md](../../../../README.md)
| 구분 | 조건 | 체크 방식 |
|------|------|-----------|
| 고령자 | customer_age >= 65 | entity_filter_json (CUSTOMER) |
| 비대면계좌 | account_type = '비대면계좌' | entity_filter_json (ACCOUNT) |
| 24시간 이내 | new_account_days <= 1 | AGG_CUS020 (신규계좌 이체) |
| 고액 이체 | transaction_amount >= 600만원 | AGG_CUS012 (고액 이체) |
