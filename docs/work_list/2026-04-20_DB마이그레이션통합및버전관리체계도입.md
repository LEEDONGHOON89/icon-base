### 2. icon.sh — DB 초기화 로직 변경

**변경 파일**: `icon.sh`

**변경 내용**:
- `setup_database()`: DB 신규 생성 시 `DB_IS_NEW=true` 플래그 설정 → `run_init_sql()` 자동 호출
- `run_init_sql()` 신규 추가: init.sql 적용 후 `icon_migrations`에 `1.0.0` 기록
- `run_migrations()`: v1.x.x 버전 포맷 지원 — 파일명 `V1_0_1__desc.sql` → 버전 `1.0.1` 추출

```bash
# 버전 추출 방식 변경
# 변경 전: sed -E 's/(V[0-9]+).*/\1/'      → V1, V2, V3...
# 변경 후: sed -E 's/^V([0-9]+)_([0-9]+)_([0-9]+)__.*/\1.\2.\3/'  → 1.0.1, 1.1.0...
```

### 4. DB 버전 관리 체계 도입 (v1.x.x)

**변경 파일**: `CLAUDE.md` (규칙 추가)

**버전 체계**:
| 구분 | 버전 | 파일 |
|---|---|---|
| 기준선 | 1.0.0 | `db/init.sql` — 신규 DB 생성 시 자동 적용 |
| 증분 변경 | 1.x.x | `db/migrations/V1_0_1__desc.sql` — 기존 DB 증분 적용 |

**파일명 규칙**: `V{major}_{minor}_{patch}__{설명}.sql`
- 점(`.`) → 언더스코어(`_`)로 표기
- 예: `V1_0_1__add_user_role_column.sql`

### 5. V1_0_1 — ds_file_system_config agent_id 컬럼 추가

**변경 파일**: `db/migrations/V1_0_1__add_agent_id_to_ds_file_system_config.sql`

**변경 이유**:
- `FileSystemConfigEntity`, `EngineDsFileSystemConfigEntity` 모두 `agent_id` 컬럼 매핑
- `ds_database_config`에는 V003에서 추가했으나 `ds_file_system_config`에 누락
- 브라우저 데이터소스 상세 페이지 진입 시 JDBC 오류 발생

```sql
ALTER TABLE ds_file_system_config
    ADD COLUMN IF NOT EXISTS agent_id VARCHAR(100) NULL;
```

**init.sql 반영**: `db/init.sql`의 `ds_file_system_config` 테이블 정의에도 동일 추가

### 6. V1_0_2 — 데이터소스 설정 테이블 ID 컬럼 길이 확장

**변경 파일**: `db/migrations/V1_0_2__fix_config_id_column_lengths.sql`

**변경 이유**:
- 코드에서 접두사 + TSID(13자) 형태로 ID 생성
- `FSR_` + 13자 = **17자**, `DB_` + 13자 = **16자** → `VARCHAR(13)` 초과 → INSERT 오류

```
오류: character varying(13) 자료형에 너무 긴 자료를 담으려고 합니다.
values (..., 'FSR_0Q3QMV70MS0FE')  ← 17자
```

**수정 대상** (VARCHAR(13) → VARCHAR(50)):

| 테이블 | 컬럼 | 생성 패턴 | 실제 길이 |
|---|---|---|---|
| `ds_file_system_config` | `ds_file_system_config_id` | `FSR_` + TSID | 17자 |
| `ds_file_system_log` | `ds_file_system_config_id` | FK 참조 | 17자 |
| `ds_database_config` | `ds_database_config_id` | `DB_` + TSID | 16자 |
| `ds_database_log` | `ds_database_config_id` | FK 참조 | 16자 |
| `ds_api_config` | `ds_api_config_id` | `API_` + TSID (예비) | 17자 |
| `ds_api_log` | `ds_api_config_id` | FK 참조 | 17자 |

**init.sql 반영**: 위 6개 컬럼 모두 `character varying(50)`으로 수정
