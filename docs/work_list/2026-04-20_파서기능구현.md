#### 파서 타입별 config_json

| 타입 | config_json 키 | 동작 |
|---|---|---|
| DELIMITER | `{"delimiter":"|","index":0}` | split 후 index번째 값 |
| FIXED_WIDTH | `{"startByte":0,"byteLength":10}` | UTF-8 바이트 기준 slice |
| REGEX | `{"pattern":"^(\\w+)","group":1}` | Matcher.group(n) |

## 주의사항

- `parser_rules.config_json` — JSONB 타입: 파서 타입별 키가 다름
  - DELIMITER: `delimiter`(필수), `index`(기본 0)
  - FIXED_WIDTH: `startByte`(필수), `byteLength`(기본 전체)
  - REGEX: `pattern`(필수), `group`(기본 0)
- 파서 삭제 시 `data_source_schemas.parser_id`는 SET NULL로 자동 해제
- 파서 타입은 생성 후 변경 불가 (PUT 요청에서 parserType 필드 없음)
- 1개 원본 필드 → N개 추출 필드: 엔진에서 원본 필드는 mappedRow에 넣지 않고 추출 결과만 저장
