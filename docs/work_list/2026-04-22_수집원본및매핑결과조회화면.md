## 주요 설계

### JSONB 확장 필터
- 형식: `key:op:value` (예: `cust_no:eq:12345678`, `account_id:like:ACC%`)
- 연산자: `eq`(완전 일치), `like`(ILIKE 부분 일치), `neq`(불일치)
- 보안: key 는 `^[a-zA-Z0-9_]+$` 정규식 검증 필수

### mapped_storages 데이터소스 필터
- `mapped_storages` 에 `data_source_id` 컬럼 없음
- `landing_records` JOIN으로 필터링: `ms JOIN lr ON ms.landing_record_id = lr.landing_record_id WHERE lr.data_source_id = ?`

### 통계 요약
- 페이지 조회와 별도로 통계 쿼리(COUNT + CASE SUM + MAX) 실행
- 필터 조건과 동일한 WHERE 절 적용 → 필터 결과 기준 통계 표시

### 상세 모달 (MappedStorageView)
- **매핑 결과 탭**: `row_data` 필드 테이블
- **원본 비교 탭**: `with-origin` API lazy 조회 → `raw_payload` vs `row_data` 나란히 표시
