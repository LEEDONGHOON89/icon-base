# 2026-04-20 표준 필드 CRUD 기능 추가

## 변경 내용 요약

표준 필드 화면(`/fields`)을 읽기전용에서 CRUD(추가/수정/삭제)가 가능한 화면으로 개선

---

## 변경 상세

### 백엔드

| 파일 | 변경 내용 |
|---|---|
| `icon-api/.../StandardFieldController.java` | POST/PUT/DELETE 엔드포인트 3개 추가 |
| `icon-api/.../StandardFieldService.java` | createStandardField / updateStandardField / deleteStandardField 메서드 추가 |
| `icon-api/.../StandardFieldDto.java` | Create/Update DTO Jackson 역직렬화 가능하도록 접근자 수정; Update에 category/dataType 필드 추가 |
| `icon-api/.../StandardFieldMapper.java` | toEntity()를 modelMapper 대신 명시적 매핑으로 교체 (fieldCategory→category 이름 불일치 방지) |

| `icon-frontend/src/app/fields/standard/page.tsx` | 읽기전용 → CRUD UI로 전면 개선 (추가 버튼, 수정/삭제 버튼, 모달 폼, 삭제 확인 다이얼로그) |

## API 엔드포인트

| Method | Path | 설명 |
|---|---|---|
| POST | `/api/v1/standard-fields` | 표준 필드 생성 |
| PUT | `/api/v1/standard-fields/{fieldId}` | 표준 필드 수정 |
| DELETE | `/api/v1/standard-fields/{fieldId}` | 표준 필드 삭제 |

---

## 필드 ID 규칙

- 영문자로 시작, 영문자/숫자/언더스코어만 허용 (`^[a-zA-Z][a-zA-Z0-9_]*$`)
- `standard_field_id` = PK 이므로 생성 후 변경 불가
- fieldName이 곧 standard_field_id (UUID 미사용)
