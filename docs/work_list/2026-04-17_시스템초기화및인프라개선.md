## 변경상세

### 1. icon.sh — 서버 실행 스크립트 개선

**변경 이유**: 서버(Rocky Linux)에서 실행 시 다수의 오류 발생
- `pg_lsclusters` 명령어 없음 (Debian 전용) → `systemctl reload` 방식으로 교체
- JAR 파일 없을 때 빌드 시도 → 서버에 소스 없으므로 오류 안내로 교체
- 프론트엔드 프로세스 감지: `pgrep -f "node.*server.js"` 실패 (Next.js standalone은 프로세스명이 `next-server`로 변경됨) → 포트 5160 기반 감지로 교체

**변경 파일**: `icon.sh`

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| PostgreSQL reload | `pg_lsclusters` (Debian 전용) | `systemctl reload postgresql-*` |
| JAR 없을 때 | Gradle 빌드 시도 | 에러 메시지 + deploy.sh 안내 |
| 프론트 프로세스 감지 | `pgrep -f "node.*server.js"` | `ss -tlnp \| grep ":5160"` |
| 마이그레이션 경로 | 고정 경로 | 소스/서버 환경 자동 감지 |
| 프론트 기동 | 누락 | `PORT=5160 HOSTNAME=0.0.0.0 nohup node server.js` |

---

### 2. deploy.sh — 배포 스크립트 구축

**변경 이유**: 작업자 PC에서 빌드 후 서버에 배포하는 워크플로우 정립

**변경 파일**: `deploy.sh`

- SSH 키 인증 방식으로 변경 (sshpass 제거)
- 백엔드: JAR 빌드 → 서버 전송 → 재기동 자동화
- 프론트엔드: Next.js standalone 빌드 → 서버 전송 → node server.js 재기동
- icon.sh 배포 기능 추가 (`./deploy.sh iconsh vm`)
- DB 마이그레이션 SQL 파일 서버 배포 추가

---

### 3. SecurityConfig — CORS 설정 수정

**변경 이유**: VM IP에서 API 호출 시 CORS 오류 발생

**변경 파일**: `icon-backend/icon-api/src/main/java/com/itmasters/icon/api/config/SecurityConfig.java`

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| CORS 허용 오리진 | `allowedOrigins("http://localhost:5160")` | `allowedOriginPatterns("*")` |

> `allowedOrigins("*")`는 credentials 사용 시 불가 → `allowedOriginPatterns("*")` 사용

---

### 4. 프론트엔드 API URL 하드코딩 제거

**변경 이유**: `localhost:11100` 하드코딩으로 VM/개발서버에서 API 호출 실패

**변경 파일**: `icon-frontend/next.config.ts`, `icon-frontend/src/lib/api.ts`

| 항목 | 변경 전 | 변경 후 |
|---|---|---|
| API URL | `NEXT_PUBLIC_API_BASE_URL: 'http://localhost:11100'` | Next.js rewrites 프록시 |
| 프록시 방식 | 없음 | `/api/*` → `http://localhost:11100/api/*` (서버 사이드) |
| axios baseURL | `process.env.NEXT_PUBLIC_API_BASE_URL` | `''` (동일 오리진, rewrites로 프록시) |

> `NEXT_PUBLIC_*` 환경변수는 빌드 시점에 고정되므로 런타임 변경 불가 → Next.js rewrites 방식으로 해결

---

### 5. DB 마이그레이션 초기 셋업 (V001~V006)

**변경 이유**: Spring Boot `ddl-auto=none` 설정으로 테이블 자동 생성 안 됨, 서버 기동 시 테이블 없음 오류

| 버전 | 파일 | 내용 |
|---|---|---|
| V001 | `V001__agent_collector_schema.sql` | 에이전트 수집기 설정 테이블 |
| V002 | `V002__create_ai_chat_tables.sql` | AI 채팅 세션/메시지 테이블 |
| V003 | `V003__alter_ds_database_config_add_agent_id.sql` | ds_database_config에 agent_id 추가 |
| V004 | `V004__create_agent_sessions.sql` | agent_sessions 테이블 (기동 시 필수) |
| V005 | `V005__create_agent_tables.sql` | agents, agent_target_configs 등 |
| V006 | `V006__core_schema.sql` | 33개 핵심 테이블 (pg_dump 기반) |

> V001은 FK 의존성 오류로 실패 → V005에서 올바른 생성 순서로 재정의
