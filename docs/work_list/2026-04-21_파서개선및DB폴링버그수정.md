### 2. JSONB 타입 바인딩 오류 수정

`config_json` (jsonb) 컬럼에 INSERT 시 `character varying → jsonb` 타입 오류 발생.

- **원인**: `columnDefinition = "jsonb"`는 DDL 힌트만 제공; Hibernate가 String을 VARCHAR로 바인딩
- **해결**: 4개 엔티티에 `@JdbcTypeCode(SqlTypes.JSON)` 추가

### 5. DB 폴링 TIMESTAMP 바인딩 버그 수정

**오류**: `timestamp without time zone > character varying` PSQLException

**원인**: `bindIncrementalParam()` / `bindParameter()`에서:
1. null 바인딩 시 `Types.VARCHAR` 고정 사용 → TIMESTAMP 컬럼 비교 시 타입 불일치
2. `Timestamp.valueOf()` 실패 시 `setString()` fallback → PostgreSQL 타입 거부

**해결**:

| 파일 | 변경 내용 |
|---|---|
| `icon-engine/.../datasource/service/DatabaseService.java` | null 바인딩에 타입별 SQL Types 사용, TIMESTAMP fallback을 `setNull(TIMESTAMP)`로 변경, 다중 포맷 파싱(`parseTimestamp()`) 추가 |
| `icon-agent/.../collector/JdbcCollector.java` | 동일 패턴 적용 |

**지원 포맷 추가** (우선순위 순):
- `yyyy-MM-dd HH:mm:ss`
- `yyyy-MM-dd HH:mm:ss.SSS`
- `yyyy-MM-ddTHH:mm:ss` (ISO 8601)
- `yyyy-MM-dd HH:mm`
- `yyyy-MM-dd`
