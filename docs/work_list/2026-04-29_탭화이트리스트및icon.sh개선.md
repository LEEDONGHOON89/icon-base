## 변경 파일 목록

### 1. `icon-frontend/src/components/Layout.tsx`
**변경 이유**: 탭 기능을 선택적으로 적용하고 싶다는 요구사항  
**변경 내용**:
- `TAB_ENABLED_PATHS` 화이트리스트 배열 추가
  - `/detections/scenarios` (시나리오 탐지)
  - `/detections/rules` (룰 탐지)
  - `/detections/actions` (탐지 조치)
  - `/detections/entity-history` (엔티티 행적)
- `isTabEnabledPath()` 헬퍼 함수 추가 — 경로 및 하위 경로 매칭
- useEffect 내 화이트리스트 외 경로 방문 시 `setActiveTabPath("")` 호출 후 early return
- 결과: 탐지 분석 4개 메뉴만 탭 바에 표시되고, 나머지 메뉴는 일반 페이지 이동으로 동작

### 2. `icon.sh`
**변경 이유**: 신규 서버 배포 시 여러 기동 오류 발생  
**변경 내용**:

#### Java 17 감지 개선
- JAVA_HOME이 설정되어 있지만 바이너리가 존재하지 않으면 unset
- Java 17 설치 후 `find /usr/lib/jvm -name "java" -path "*java-17*"` 로 명시적 경로 탐색
- alternatives --list fallback (RedHat 계열)
- 설치 후 버전 검증

#### PostgreSQL 패스워드 보호
- `ALTER USER postgres PASSWORD '1234'` 가 매번 start 시 실행되던 문제 수정
- `DB_IS_NEW = true` 일 때만 (신규 DB 생성 시에만) 패스워드 설정

#### 프론트엔드 포트 감지 fallback
- `ss -tlnp` 가 동작하지 않는 서버 환경 대응
- `ss → netstat → lsof` 순서로 fallback 체인 구성
- 1초 단위 재시도 루프 (최대 15회)로 startup 완료 감지

### 3. `db/migrations/V1_0_16__add_agent_id_to_file_system_config.sql` (신규)
**변경 이유**: `FileSystemConfigEntity.java` 에 `agent_id` 필드가 존재하지만 DB 테이블에 컬럼이 없어 데이터 소스 조작 시 오류 발생  
**변경 내용**:
```sql
ALTER TABLE public.ds_file_system_config
    ADD COLUMN IF NOT EXISTS agent_id VARCHAR(100) NULL;
```

### 4. `db/init.sql`
**변경 이유**: init.sql 에 agent_id 컬럼 반영 (신규 설치 시 정합성 유지)  
**변경 내용**: `ds_file_system_config` 테이블 정의에 `agent_id character varying(100) NULL` 추가

### 5. `deploy.sh`
**변경 이유**: 배포 서버 정보 변경 (dev4→dev1, dev6→dev2)  
**변경 내용**: 서버 IP, 포트, 경로 업데이트
