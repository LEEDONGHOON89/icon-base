# 미사용 에이전트 수집기 테이블 삭제

## 변경일자
2026-04-22

## 변경내용
`agent_collector_configs` / `agent_collector_file_configs` / `agent_collector_jdbc_configs` 테이블 및 관련 코드 전체 삭제

## 배경
- [2026-04-21] AgentSnapshotService 도입으로 수집기 설정의 단일 진실 공급원(Single Source of Truth)이
  `ds_file_system_config` / `ds_database_config` 로 이전됨
- 구 CRUD 기반 collector API (`/api/rpc/agents/{id}/target-configs/{id}/collectors`)는 더 이상 사용되지 않음
- 3개 테이블 및 5개 Java 클래스, 프론트엔드 함수 일체 제거

## 현재 아키텍처 (변경 후)
```
에이전트 연결 → AgentSnapshotService.onAgentConnected()
              → ds_file_system_config / ds_database_config 직접 조회
              → COLLECTORS_SYNC 메시지 에이전트에 푸시

데이터소스 설정 저장 → AgentSnapshotService.pushSnapshot()
                    → 동일 경로로 전체 스냅샷 재전송
```
