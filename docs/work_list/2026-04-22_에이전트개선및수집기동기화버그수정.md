## 1. 버그 수정 — 에이전트 해제 시 수집기 미제거

### 문제
수집기에서 에이전트 설정을 제거(agentId → null)해도 에이전트가 기존 수집기를 계속 보유하는 버그.

### 원인
`DataSourceConfigService.saveConfig()` 에서 `entity.getAgentId()`로 체크하는 시점이
이미 `applyAgentLink(null)` 적용 후였기 때문에 조건 `!= null` 이 항상 false가 되어
기존 에이전트에 스냅샷이 전혀 전송되지 않음.

### 수정
저장 전에 기존 agentId를 `prevAgentId`로 캡처하여, 변경 시 기존 에이전트에도 스냅샷 전송.

**커버되는 시나리오:**
| 변경 | 동작 |
|---|---|
| null → "agent-001" | 신규 에이전트에 수집기 추가 |
| "agent-001" → null | 기존 에이전트에서 수집기 제거 |
| "agent-001" → "agent-002" | 기존에서 제거 + 신규에 추가 (양쪽 모두 스냅샷) |
| "agent-001" → "agent-001" | 동일 에이전트, 1회만 전송 |

### 수정 파일
- `icon-backend/icon-api/.../service/DataSourceConfigService.java`
  - FILE_SYSTEM_REALTIME, DATABASE 양쪽 모두 수정
