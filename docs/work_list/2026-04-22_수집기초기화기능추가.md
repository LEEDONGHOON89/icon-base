# 2026-04-22 수집기 초기화 기능 추가

## 작업 개요

수집기의 `last_position`을 초기화하여 파일 또는 DB를 처음부터 재수집할 수 있는 기능 추가.
에이전트 수집(COLLECTOR_RESET WebSocket 메시지)과 백엔드 직접 수집(DB/파일 직접 초기화) 양방향 지원.

---

## 1. 초기화 방식 요약

| # | 타입                 | 에이전트 | 초기화 방법                                             |
|---|----------------------|----------|---------------------------------------------------------|
| 1 | DATABASE             | ❌ 없음   | `ds_database_config.last_processed_value, last_query_time = NULL` |
| 2 | DATABASE             | ✅ 있음   | WebSocket `COLLECTOR_RESET` → 에이전트 `watermark.dat` 삭제 후 재시작 |
| 3 | FILE_SYSTEM_REALTIME | ❌ 없음   | `data/file-realtime/{dataSourceId}/positions.json` 삭제 |
| 4 | FILE_SYSTEM_REALTIME | ✅ 있음   | WebSocket `COLLECTOR_RESET` → 에이전트 `positions.dat` 삭제 후 재시작 |
| 5 | FILE_SYSTEM          | ❌ 없음   | `ds_file_system_log` 해당 config 레코드 삭제             |

## 2. 백엔드 변경 내역

### 신규 파일

- `icon-api/.../application/service/CollectionResetService.java`
  - 데이터소스 타입 + agentId 유무로 5가지 케이스 분기
  - `reset(dataSourceId)` → 적절한 초기화 후 결과 Map 반환

- `icon-api/.../adapter/in/web/CollectionResetController.java`
  - `POST /api/v1/data-sources/{dataSourceId}/reset-collection`

### 수정 파일

- `icon-api/.../entity/DatabaseConfigEntity.java`
  - `resetWatermark()` 메서드 추가 (`last_processed_value`, `last_query_time` → NULL)

- `icon-engine/.../realtime/FileSystemRealtimePositionStore.java`
  - `delete(dataSourceId)` 메서드 추가 — `positions.json` 파일 삭제

- `icon-api/.../repository/FileSystemLogJpaRepository.java`
  - `deleteByDsFileSystemConfigId(@Param("configId") String)` JPQL 쿼리 추가 (삭제 건수 반환)

- `icon-rpc-server/.../AgentRpcWebSocketHandler.java`
  - `sendCollectorReset(agentId, targetId, collectorId)` 메서드 추가
  - 페이로드: `{ type: "COLLECTOR_RESET", targetId, collectorId }`

## 3. 에이전트 변경 내역

### 수정 파일

- `icon-agent/.../rpc/RpcClient.java`
  - `CollectorResetCallback` 인터페이스 추가
  - `collectorResetCallback` 필드 추가 (생성자 파라미터)
  - `WsListener.handleMessage()` — `COLLECTOR_RESET` 메시지 분기 추가
  - `handleCollectorReset(node)` — collectorId 파싱 후 콜백 호출

- `icon-agent/.../target/TargetContext.java`
  - `resetCollector(collectorId)` 메서드 추가
    1. 실행 중 수집기 중지 (FILE/JDBC)
    2. `data/{targetId}/{collectorId}/positions.dat` 삭제
    3. `data/{targetId}/{collectorId}/watermark.dat` 삭제
    4. `AuditLogger.configChanged(targetId, "COLLECTOR_RESET", collectorId)` 기록
    5. `knownCollectors`에서 설정 조회 후 재시작
  - `deletePositionFile(Path)` 헬퍼 메서드 추가
  - `RpcClient` 생성 시 `CollectorResetCallback` 등록: `(tid, cid) -> resetCollector(cid)`
