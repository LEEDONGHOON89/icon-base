## 감사 이벤트 목록

| 이벤트 | 발생 지점 | 기록 내용 |
|---|---|---|
| `AGENT_START` | 에이전트 기동 직후 | agentId, host |
| `AGENT_STOP` | 종료 훅 시작 시 | agentId |
| `TARGET_CONNECTED` | WebSocket 연결 성공 | targetId, endpoint |
| `TARGET_DISCONNECTED` | WebSocket 연결 끊김/오류 | targetId, reason |
| `COLLECTOR_STARTED` | 수집기 시작/재시작 | targetId, collectorId, type, detail |
| `COLLECTOR_STOPPED` | 수집기 중지 | targetId, collectorId, type |

## JVM 옵션 변경 내역

```bash
# 변경 전
-XX:MaxDirectMemorySize=8192m  # 제거 (불필요한 대용량 설정)
-Xmx2048m                      # 축소

# 변경 후 (백엔드)
-Xms256m -Xmx512m
-XX:+UseG1GC -XX:MaxGCPauseMillis=200 -XX:G1ReservePercent=10

# 신규 (에이전트)
-Xms64m -Xmx256m
-XX:+UseG1GC -XX:MaxGCPauseMillis=100
```
