## 3. DestinationType.ENTITY_ATTRIBUTES 오류 수정

### 원인

`DestinationType` enum은 `EVENT_STREAM`, `ENTITY`, `BOTH` 만 존재하나,
`ProfileDetailPanel.tsx` 드롭다운 옵션 값이 `ENTITY_ATTRIBUTES`로 잘못 정의되어
프로파일 등록 시 `No enum constant` 오류 발생.

### 수정 파일

- `icon-frontend/src/components/profile/ProfileDetailPanel.tsx`
  - `ENTITY_ATTRIBUTES` → `BOTH` 변경, `ENTITY` 옵션 신규 추가
  - 조건문 `=== "ENTITY_ATTRIBUTES"` → `=== "ENTITY" || === "BOTH"` 수정

- `icon-api/.../ProfileEntity.java`
  - 잘못된 주석 `ENTITY_ATTRIBUTES` → `BOTH`, `ENTITY` 로 수정

- `icon-engine/.../Step2Processor.java`
- `icon-engine/.../Prep25EventBasedEntityUpdateProcessor.java`
  - 동일 주석 정정

### DB 마이그레이션

- `db/migrations/V1_0_15__fix_destination_type_entity_attributes.sql` (신규)
  - 기존 저장된 `destination_type = 'ENTITY_ATTRIBUTES'` 값을 `'BOTH'`로 일괄 변환

## 4. 시나리오 수정 폼 버그 수정

### 4-1. 기본정보 미로드 버그

**원인**: `isMetadataLoaded = riskLevels.length > 0 && ...` 조건에서
탐지 영역 데이터가 0건이면 영원히 `false` → 폼 초기화 불가

**수정**: `isSuccess` 플래그 사용으로 변경 (0건이어도 쿼리 완료 시 `true`)

- `icon-frontend/src/app/scenarios/ScenarioForm.tsx`

### 4-2. 엔티티 필터 저장 안되는 버그

**원인 1**: TanStack Query `staleTime=0` 기본값 → 창 포커스 복귀 시 시나리오 재조회
→ `scenario` 객체 참조 변경 → init effect 재실행 → `setEntityFilters([])` 초기화

**원인 2**: `EntityFilterEditor`의 `onChange` useEffect가 마운트 시에도 실행되어
불필요한 부모 리렌더 발생 (순환 업데이트 구조)

**수정 파일**:

- `icon-frontend/src/app/scenarios/ScenarioForm.tsx`
  - `lastInitializedScenarioId` 상태 추가 — 동일 scenarioId 재초기화 방지
  
- `icon-frontend/src/app/scenarios/[id]/edit/page.tsx`
  - 시나리오 쿼리에 `staleTime: 5 * 60 * 1000` 추가

- `icon-frontend/src/app/scenarios/components/EntityFilterEditor.tsx`
  - `isMountedRef` 추가 — 마운트 직후 `onChange` 호출 스킵
