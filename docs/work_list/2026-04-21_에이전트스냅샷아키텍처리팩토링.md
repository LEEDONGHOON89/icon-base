# 2026-04-21 에이전트 스냅샷 아키텍처 리팩토링 (Phase 1~3)

## 작업 개요

`agent_collector_configs` / `agent_collector_file_configs` / `agent_collector_jdbc_configs` 테이블을
`ds_file_system_config` / `ds_database_config` 테이블로 통합하고,
에이전트 연결 시 전체 수집기 스냅샷을 자동으로 동기화하는 구조로 재설계.

## 핵심 설계 변경

### Before (구 아키텍처)
```
수집기 저장 → agent_collector_configs INSERT/UPDATE → COLLECTORS_SYNC (단일)
에이전트 연결 → (스냅샷 없음, 에이전트가 자체 config.yaml 사용)
```

### After (신 아키텍처)
```
수집기 저장 → ds_*_config 직접 저장 → pushSnapshot() → COLLECTORS_SYNC (전체)
에이전트 연결 → AgentConnectedEvent → onAgentConnected() → pushSnapshot() → COLLECTORS_SYNC (전체)
```

### 단일 진실 공급원 (Single Source of Truth)
- FILE 수집기: `ds_file_system_config.agent_id = <agentId>` 행들
- JDBC 수집기: `ds_database_config.agent_id = <agentId>` 행들
- `agent_collector_*` 테이블은 더 이상 신규 데이터를 받지 않음 (기존 데이터 유지, 향후 드랍 예정)
